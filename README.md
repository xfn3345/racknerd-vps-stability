## 稳定性拆成三件事看：在线率、硬件冗余、网络线路

在线率这块，RackNerd 的口碑大致在 99.9% 这个水平，官方服务条款里的 SLA 写的是 99.999% 网络与电力，两个数字不是一回事，后面单独讲。

硬件冗余是它相对同价位商家的强项。VPS 全线跑 RAID-10 SSD 阵列，母机用 Intel Xeon，网络侧走 Noction IRP 做路由优化。单盘故障不至于直接丢数据，这一点比只挂单块 SATA 盘的低价机器靠谱。

网络线路就得说实话了。RackNerd 采购的是普通国际线路（163），没有花大价钱买中国电信的精品回程资源。这意味着晚高峰（北京时间 20:00 之后）从国内访问美西节点，丢包率会往上走，SSH 偶尔卡一下。这是 163 线路的通病，不是 RackNerd 一家的毛病，但你得知道自己买的是什么。

把这三件事分开看，结论就清楚了：机器本身不容易挂，线路在高峰期会挤。如果你的业务强依赖国内晚高峰的低延迟，这台机器不合适；如果你能接受白天流畅、晚上慢一截，它的综合表现对得起价格。

## 前排文章很少提的几个限制

**不退款，取消即删数据。** 官方服务条款里没有常规退款这一项，VPS、共享主机、独立服务器都不退。后台点“立即取消服务”，系统会在 24 小时内终止服务并删除数据，不会自动退款。条款里还有一句写得很直白：RackNerd 不对数据完整性负责，建议客户自己保留异地备份。这条决定了你第一次买不能冲动上年付。

**SLA 是网络与电力口径，不等于你的机器 99.999% 可用。** 条款承诺每月 99.999% 的网络传输与电力，超出部分按每小时赔付月费的 2%，上限 50%，需要在 30 天内邮件申请。关键是后半句：每月最多 180 分钟的公告维护时间不计入 SLA。也就是说，计划内维护造成的停机不算违约，官方会提前在状态页公告。第三方监控看到的单台 VPS 可达率，落在 99.9% 到 99.99% 这个区间是正常水平。拿 99.999% 当“我的机器一年只挂 5 分钟”来理解，会失望。

**不允许嵌套虚拟化。** 条款明确禁止在 KVM VPS 里再跑虚拟机、VPS 服务或需要硬件虚拟化的模拟器，除非拿到书面批准。Docker、Docker Compose、LXC/LXD、Kubernetes、K3s 这类容器负载是允许的，但同样受公平使用政策约束。想开小鸡转售的，得去买独立服务器。

**换 IP 要花钱，IPv6 只有部分节点。** IP 被墙可以在控制面板自助付费更换，工单申请也行，费用按套餐不同，下单前问清楚。免费 IPv6 目前在洛杉矶和法国节点可以工单申请，其他节点还没铺开。

**升级可以，降级不行。** 通过 SolusVM 面板可以随时升到更高一档，过程需要一次重启，停机大约一分钟。往下调不支持。

**续费价格。** 官方在 Reddit 上回复过这个问题，原话是促销结束后现有客户的价格锁定，“RackNerd never raised prices on active customers”。多位用户也确认促销机按促销价续费。这条属于官方公开表态加用户反馈，不是写进条款的承诺，下单时看一眼订单页的续费说明更稳妥。

## 买回来怎么确认稳不稳：四步自检

新机器开通后先别急着部署业务，花两周跑完这四步。

1. **装监控。** UptimeRobot 或同类免费服务，5 分钟 ping 一次，跑满两周看掉线次数和最长断连时长。两周内掉线超过两次、单次超过 5 分钟，就要考虑换机房或换商家。
2. **测路由。** 从自己常用的国内网络跑 `mtr` 到 VPS IP，看丢包率和有没有绕路。这一步能验证你选的机房对你的运营商是不是真的合适。
3. **压带宽。** 用 `iperf3` 分别在北京时间 20:00–23:00 和凌晨测上下行，两个时段差距过大，说明线路在高峰期被挤得厉害。
4. **验存储。** 跑 `fio` 测随机读写 IOPS，确认 RAID-10 的实际表现，避免拿到降级阵列或者邻居正在压盘的机器。

日常运维上还有几件事顺手做掉：系统选 Debian 12 或 Ubuntu 22.04 LTS 这类长期支持版本；关掉不必要的端口和服务，开 fail2ban，SSH 改非默认端口、禁用 root 密码登录；重要数据用 rclone 同步到 S3 或另一台机器，官方条款已经写明不负责数据完整性，备份得自己兜。

可以在 SolusVM 面板升到更高一档，需要一次重启，停机约一分钟。不支持降级，买之前把配置想清楚。

**IP 被墙了怎么办？**

**能跑 Docker 或者开小鸡吗？**
